# 💻 Laptop Price Prediction & Recommendation System

An end-to-end Machine Learning web application that predicts laptop prices and recommends similar laptops based on user specifications.

## Features

- Laptop Price Prediction
- Similar Laptop Recommendation
- Interactive Web Interface
- Flask Backend
- Machine Learning Model

## Tech Stack

- Python
- Flask
- Scikit-learn
- XGBoost
- HTML
- CSS
- JavaScript

## Installation

```bash
pip install -r requirements.txt
python app.py
```

Visit:

```
http://127.0.0.1:5000
```
